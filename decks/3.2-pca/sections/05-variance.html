Act 5 / Recipe

PCA, step by step

  1. Centre each column (and standardise if the units differ).
  2. Covariance: \(C = \tfrac1m X^TX\), size \(n \times n\).
  3. Eigenvectors and eigenvalues of \(C\), sorted so \(\lambda_1 \ge \dots \ge \lambda_n\).
  4. Keep the first \(k\) eigenvectors: \(P_k\), size \(n \times k\).
  5. New data: \(\hat X_k = XP_k\), size \(m \times k\).
Act 5 / Worked example, step 1

Centre the columns

Four samples, two features, straight off the measuring instrument:

$$X_{\text{raw}} = \begin{bmatrix}7&5\\3&1\\6&2\\4&4\end{bmatrix}$$

Column means: \(\bar x = \tfrac{20}{4} = 5\), \(\bar y = \tfrac{12}{4} = 3\).

$$X = \begin{bmatrix}7-5&5-3\\3-5&1-3\\6-5&2-3\\4-5&4-3\end{bmatrix} = \begin{bmatrix}2&2\\-2&-2\\1&-1\\-1&1\end{bmatrix}$$

Both features are in the same units here, so no standardising. These are the four points from Act 2.

Act 5 / Worked example, step 2

Build the covariance matrix

$$X^TX = \begin{bmatrix}4+4+1+1 & 4+4-1-1\\ 4+4-1-1 & 4+4+1+1\end{bmatrix}$$

$$C = \tfrac14 X^TX = \begin{bmatrix}2.5&1.5\\1.5&2.5\end{bmatrix}$$

\(m = 4\), and \(C\) is \(2 \times 2\): one row and column per feature.

Variance 2.5 in each feature, covariance 1.5 between them. Total variance \(2.5 + 2.5 = 5\).

Act 5 / Worked example, step 3

Eigenvectors and eigenvalues of \(C\)

$$(2.5 - \lambda)^2 - 1.5^2 = 0 \quad\Rightarrow\quad \lambda_1 = 4,\ \ \lambda_2 = 1$$

\(C - 4I = \begin{bmatrix}-1.5&1.5\\1.5&-1.5\end{bmatrix}\), so \(\mathbf p_1 = \tfrac{1}{\sqrt2}(1, 1)\).

\(C - I = \begin{bmatrix}1.5&1.5\\1.5&1.5\end{bmatrix}\), so \(\mathbf p_2 = \tfrac{1}{\sqrt2}(1, -1)\).

Check: \(\lambda_1 + \lambda_2 = 5\), the total variance from step 2. Sorted largest first, so \(\mathbf p_1\) is the first principal component.

Act 5 / Worked example, steps 4 and 5

Keep one component and project

Take \(k = 1\): \(P_1 = \tfrac{1}{\sqrt2}\begin{bmatrix}1\\1\end{bmatrix}\), size \(2 \times 1\).

Share kept: \(\dfrac{\lambda_1}{\lambda_1 + \lambda_2} = \dfrac45 = 80\%\).

$$\hat X_1 = XP_1 = \begin{bmatrix}2\sqrt2\\-2\sqrt2\\0\\0\end{bmatrix} \approx \begin{bmatrix}2.83\\-2.83\\0\\0\end{bmatrix}$$

Size \(4 \times 1\): each point is now one number.

Variance of that column: \(\tfrac14(8 + 8 + 0 + 0) = 4 = \lambda_1\), as promised.

Act 5 / Worked example, the loss

What the 20% cost us

Rebuild each sample from its one number: \(\ \mathbf{\hat x}_i = \alpha_i\,\mathbf p_1 + (\bar x, \bar y)\). Sample 3 has \(\alpha_3 = 0\), so it rebuilds as \(0 \cdot \mathbf p_1 + (5,3) = (5,3)\).

sampleoriginal\(\alpha_i\)rebuiltlost
1\((7, 5)\)\(2\sqrt2\)\((7, 5)\)\(0\)
2\((3, 1)\)\(-2\sqrt2\)\((3, 1)\)\(0\)
3\((6, 2)\)\(0\)\((5, 3)\)\(\|(1,-1)\|^2 = 2\)
4\((4, 4)\)\(0\)\((5, 3)\)\(\|(-1,1)\|^2 = 2\)

Samples 1 and 2 sat on the \(\mathbf p_1\) line through the mean, so they come back exactly. Samples 3 and 4 were off it, and collapse onto the mean.

Mean squared error \(= \tfrac14(0 + 0 + 2 + 2) = 1 = \lambda_2\), the eigenvalue we dropped.

Act 5 / Choosing \(k\)

How many components?

$$\text{share kept} = \frac{\lambda_1 + \dots + \lambda_k}{\lambda_1 + \dots + \lambda_n}$$
  • Pick the smallest \(k\) that keeps 90% or 95%.
  • Or plot the eigenvalues and cut where the curve flattens.
  • Or try a few values of \(k\) and keep the one that works best downstream.

Three dimensions down to two

Keep the plane of \(\mathbf p_1\) and \(\mathbf p_2\), drop \(\mathbf p_3\). Each point moves to its shadow on that plane.
