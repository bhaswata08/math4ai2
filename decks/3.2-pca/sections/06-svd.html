PCA through the SVD

The SVD of the data matrix contains everything PCA needs, and you never have to form \(X^TX\).

12 min
Act 6 / The link

From \(X = U\Sigma V^T\) to \(C\)

Take the SVD of the centred data matrix (Block 3.1): \(X = U\Sigma V^T\), with \(U\) of size \(m\times m\), \(\Sigma\) of size \(m\times n\), \(V\) of size \(n\times n\).

$$C = \frac1m X^TX = \frac1m V\Sigma^TU^TU\Sigma V^T = V\,\frac{\Sigma^T\Sigma}{m}\,V^T$$

  • This has the form \(Q\Lambda Q^T\): it is the spectral decomposition of \(C\).
  • Principal directions: \(\mathbf p_j = \mathbf v_j\), the right singular vectors.
  • Eigenvalues: \(\lambda_j = \sigma_j^2/m\), already in decreasing order.
  • Scores: \(\hat X = XV = U\Sigma\). Column \(j\) is \(\sigma_j\mathbf u_j\).
Act 6 / Example

The four points, by SVD

$$X^TX = \begin{bmatrix}10&6\\6&10\end{bmatrix}: \ \sigma_1^2 = 16,\ \sigma_2^2 = 4$$

\(\sigma_1 = 4,\ \sigma_2 = 2\)
\(\lambda_1 = 16/4 = 4,\ \lambda_2 = 4/4 = 1\) ✓

\(\mathbf v_1 = \tfrac1{\sqrt2}(1, 1)\), so

$$\mathbf u_1 = \frac{X\mathbf v_1}{\sigma_1} = \frac{1}{\sqrt2}\begin{bmatrix}1\\-1\\0\\0\end{bmatrix}, \quad \sigma_1\mathbf u_1 = \begin{bmatrix}2\sqrt2\\-2\sqrt2\\0\\0\end{bmatrix}$$

\(\sigma_1\mathbf u_1\) is exactly the first column of \(\hat X = XP\) from Act 3.

Act 6 / In practice

Why libraries use the SVD

More accurate

Multiplying \(X^TX\) out loses precision in the small components. The SVD works on \(X\) directly.

Cheaper when \(n \gg m\)

Faces: 400 images of 4096 pixels. \(C\) would be \(4096 \times 4096\). The SVD of the \(400 \times 4096\) matrix \(X\) gives the same directions without ever building it.

In code, PCA is almost always "centre, then SVD".

Act 6 / Code

Two routes, one answer

# eigendecomposition
Xc = X - X.mean(axis=0)
C = Xc.T @ Xc / len(Xc)
lam, P = np.linalg.eigh(C)
order = np.argsort(lam)[::-1]
lam, P = lam[order], P[:, order]
Z = Xc @ P[:, :k]
# SVD
Xc = X - X.mean(axis=0)
U, S, Vt = np.linalg.svd(
    Xc, full_matrices=False)
lam = S**2 / len(Xc)
P = Vt.T
Z = U[:, :k] * S[:k]
  • Each column of \(P\) is fixed only up to sign: \(\mathbf p_j\) and \(-\mathbf p_j\) are both unit eigenvectors. Two libraries can return opposite signs.
