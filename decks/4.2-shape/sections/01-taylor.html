Where the factorial comes from

Differentiating \(c_4x^4\) four times leaves \(4\cdot3\cdot2\cdot1 = 24\). Four derivatives also bring \(\cos\) back to itself, so \(\cos^{(4)}(0) = \cos 0 = 1\) and \(c_4 = 1/24\).

Act 1 / Where the factorial comes from

Differentiate the polynomial and read off \(c_n\)

Write the approximation as an unknown polynomial in \((x-a)\) and find the coefficients one at a time. Setting \(x = a\) kills every term that still carries a factor of \((x-a)\), so each derivative exposes exactly one coefficient.

$$f(x) = c_0 + c_1(x-a) + c_2(x-a)^2 + c_3(x-a)^3 + c_4(x-a)^4 + \cdots$$
$$f(a) = c_0$$every other term has a factor \((x-a)\)
$$f'(x) = c_1 + 2c_2(x-a) + 3c_3(x-a)^2 + \cdots \;\Rightarrow\; f'(a) = c_1 = 1!\,c_1$$the power rule brings each exponent down
$$f''(x) = 2c_2 + 3\cdot 2\,c_3(x-a) + \cdots \;\Rightarrow\; f''(a) = 2c_2 = 2!\,c_2$$\(c_2\) has been multiplied by \(2\), then \(1\)
$$f'''(x) = 3\cdot 2\cdot 1\,c_3 + 4\cdot3\cdot2\,c_4(x-a) + \cdots \;\Rightarrow\; f'''(a) = 3!\,c_3$$\(c_3\) picks up \(3\), then \(2\), then \(1\)

Each line gives one coefficient: \(c_1 = f'(a)/1!\), \(c_2 = f''(a)/2!\), \(c_3 = f'''(a)/3!\).

Act 1 / Where the factorial comes from

The \(n\)-th derivative leaves \(n!\,c_n\)

Differentiate \(c_n(x-a)^n\) \(n\) times. The power rule brings down \(n\), then \(n-1\), then \(n-2\), down to \(1\):

$$\frac{d^n}{dx^n}\,c_n(x-a)^n = n\,(n-1)\,(n-2)\cdots 1 \cdot c_n = n!\,c_n$$

Lower terms

Degree below \(n\) differentiates to \(0\) after \(n\) steps, so nothing from them survives.

Higher terms

Degree above \(n\) still carries a factor \((x-a)\), so it vanishes at \(x = a\).

$$f^{(n)}(a) = n!\,c_n \qquad\Longrightarrow\qquad \boxed{\,c_n = \frac{f^{(n)}(a)}{n!}\,}$$

The factorial undoes the scaling that \(n\) differentiations put on a degree-\(n\) term.

Around any point

Tangent line, then curvature at \(a=1\), read at \(x = 1+h\). Shrink \(h\) by 5: the linear error falls about 25 times, the quadratic error about 100.
