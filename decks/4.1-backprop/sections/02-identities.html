Act 2 / Check one by hand

\(\nabla(\mathbf a^{\top}\mathbf x) = \mathbf a\)

$$\mathbf a^{\top}\mathbf x = a_1 x_1 + a_2 x_2 + \cdots + a_n x_n \quad\Longrightarrow\quad \frac{\partial}{\partial x_i} = a_i$$

Every identity in the table can be checked this way: write the sum, differentiate one entry.

Gradients of a linear layer

Each weight's gradient is its input times its error. Sent backwards, the error is weighted by the same weights.

Act 2 / A linear layer

\(\mathbf z = W\mathbf x + \mathbf b\), loss \(L(\mathbf z)\)

$$\frac{\partial L}{\partial W} = \boldsymbol\delta\,\mathbf x^{\top}$$

outer product: \(m \times 1\) times \(1 \times n\)

$$\frac{\partial L}{\partial \mathbf x} = W^{\top}\boldsymbol\delta$$

passed back to the previous layer

Here \(\boldsymbol\delta = \partial L/\partial \mathbf z\). These two lines are a whole backward pass through one layer.
