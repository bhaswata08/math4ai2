Act 3 of 6

The network and the objective

Before you can differentiate a network you have to write one down. Layers, parameters, and the one number you are trying to make small.

Act 3 / The model

A feedforward network, in two lines

The input is a vector \(\mathbf x \in \mathbb R^n\). The network has \(L\) layers: \(L-1\) hidden ones and an output layer. Call the input layer the \(0\)-th layer, so \(\mathbf h_0 = \mathbf x\).

Each neuron splits into two halves. The pre-activation is an affine map of the layer below:

$$\mathbf a_i = \mathbf b_i + W_i \mathbf h_{i-1}$$

The activation applies a nonlinearity \(g\) entry by entry:

$$\mathbf h_i = g(\mathbf a_i)$$

At the top, a possibly different function \(O\) turns the last pre-activation into the prediction:

$$\mathbf h_L = \hat{\mathbf y} = f(\mathbf x) = O(\mathbf a_L)$$
shape
\(W_i,\ \mathbf b_i\) for \(0 < i < L\)\(\mathbb R^{n\times n}\), \(\mathbb R^{n}\)
\(W_L,\ \mathbf b_L\)\(\mathbb R^{k\times n}\), \(\mathbb R^{k}\)

Two equations, repeated \(L\) times. Everything else in this act and the next is bookkeeping on top of them.

Act 3 / Unrolled

The whole network is one nested function

Take \(L = 3\) and substitute each line into the next:

$$\hat{\mathbf y} \;=\; O\Big(\,\underbrace{W_3\,g\big(\underbrace{W_2\,g(\underbrace{W_1\mathbf x + \mathbf b_1}_{\mathbf a_1}) + \mathbf b_2}_{\mathbf a_2}\big) + \mathbf b_3}_{\mathbf a_3}\,\Big)$$
  • Affine, squash, affine, squash, affine, output. No other kind of step appears.
  • Every parameter sits inside a composition, which is why the chain rule is the only tool Act 4 needs.

A deep network is not a new kind of object. It is \(g\) and matrix multiplication, alternated.

Act 3 / The parameters

Gradient descent does not change

Collect every weight and bias into one symbol:

$$\theta = [\,W_1, W_2, \dots, W_L,\ \mathbf b_1, \mathbf b_2, \dots, \mathbf b_L\,]$$

Then the update rule is the one from Block 3.4, unchanged:

$$\theta_{t+1} \;=\; \theta_t \;-\; \eta\,\nabla_{\theta_t}$$
gradient_descent():
  t = 0
  initialize theta_0
  while t++ < max_iterations:
    theta_{t+1} = theta_t - eta * grad(theta_t)

For one neuron, \(\theta\) was \([w, b]\) and \(\nabla_\theta\) was two numbers. For a network, \(\theta\) is a pile of matrices.

The algorithm does not care. It only needs someone to hand it \(\nabla_\theta\).

Act 3 / The ask

What \(\nabla_\theta\) actually contains

One partial derivative per parameter, arranged to match the parameter it belongs to:

$$\nabla_{W_1}, \nabla_{W_2}, \dots, \nabla_{W_{L-1}} \in \mathbb R^{n\times n}, \qquad \nabla_{W_L} \in \mathbb R^{k\times n}$$
$$\nabla_{\mathbf b_1}, \dots, \nabla_{\mathbf b_{L-1}} \in \mathbb R^{n}, \qquad \nabla_{\mathbf b_L} \in \mathbb R^{k}$$

A 784–256–256–10 network has about 270,000 of these, and that is a small one. Writing out the full \(\nabla_\theta\) as one flat row would fill this slide and several more.

So two questions are left, and they are the rest of this block. How do we choose \(L(\theta)\)? And how do we compute \(\nabla_\theta\) without touching each entry separately?

Act 3 / Choosing the loss

The loss follows the task, not the network

Predicting numbers. Suppose each target is a vector of real ratings, \(\mathbf y_i \in \mathbb R^3\). Then \(\hat{\mathbf y}\) must be free to take any real value, so \(O\) is linear and the deviation is measured by squared error:

$$L(\theta) \;=\; \frac{1}{N}\sum_{i=1}^{N}\sum_{j=1}^{3}\big(\hat y_{ij} - y_{ij}\big)^2$$
  • A logistic \(O\) would be wrong here: it pins \(\hat y_i\) into \((0,1)\) and the ratings are not.
  • Nothing below the output layer changes. Only \(O\) and \(L\) did.

The output function and the loss are a matched pair. Pick the pair that fits what \(\mathbf y\) is.

Act 3 / Choosing the loss

Classification needs a distribution

Now sort an image into one of \(k\) classes. The target is one-hot:

$$\mathbf y = [\,1,\ 0,\ 0,\ 0\,]$$

That is already a probability distribution: non-negative, sums to one. Squared error would work, but it ignores this.

So make \(\hat{\mathbf y}\) a distribution too. The output function that does it is softmax:

$$\hat y_j \;=\; O(\mathbf a_L)_j \;=\; \frac{e^{a_{L,j}}}{\sum_{i=1}^{k} e^{a_{L,i}}}$$
  • Exponentiating makes every entry positive.
  • Dividing by the total makes them sum to one.
  • The ordering of the \(a_{L,i}\) survives, so the largest pre-activation stays the most likely class.

Softmax is the cheapest way to turn \(k\) unconstrained numbers into \(k\) probabilities.

Act 3 / Cross entropy

Comparing two distributions

With both \(\mathbf y\) and \(\hat{\mathbf y}\) distributions, the natural discrepancy is cross entropy:

$$L(\theta) \;=\; -\sum_{c=1}^{k} y_c \log \hat y_c$$

But \(\mathbf y\) is one-hot. For true class \(\ell\), \(y_\ell = 1\) and every other term vanishes:

$$\boxed{\,L(\theta) \;=\; -\log \hat y_\ell\,}$$
  • Minimising \(-\log \hat y_\ell\) is maximising \(\log \hat y_\ell\), the log-likelihood of the data.
  • \(\hat y_\ell\) is the probability the network assigns to the right answer. Push it towards 1.

A sum over \(k\) classes collapses to one term. That is why the gradients in Act 4 stay short.

Act 3 / And it does depend on \(\theta\)

Is \(\hat y_\ell\) a function of the parameters?

It has to be, or there would be nothing to differentiate. Unroll it for \(L = 3\):

$$\hat y_\ell \;=\; \Big[\,O\big(W_3\,g(W_2\,g(W_1\mathbf x + \mathbf b_1) + \mathbf b_2) + \mathbf b_3\big)\Big]_\ell$$

Every \(W_i\) and every \(\mathbf b_i\) appears. So the objective

$$\min_\theta \; L(\theta) \;=\; -\log \hat y_\ell$$

is a genuine optimisation problem in \(\theta\), and gradient descent is allowed to attack it.

For the rest of this block: softmax output, cross-entropy loss. Every gradient in Act 4 is derived for that pair, and only the first step would change if you swapped it.
