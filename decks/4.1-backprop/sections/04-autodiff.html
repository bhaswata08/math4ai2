Automatic differentiation

Not symbolic, not numeric: the chain rule, applied to a recorded computation.

Tracing the graph

The forward pass stores values. The reverse pass multiplies by local slopes, and \(y\) adds up two contributions.

Act 4 / A worked graph

\(f(x, y) = (x + y)\,y\) at \(x = 2,\ y = 3\)

\(f = u \cdot y\)\(15\)\(\bar f = 1\)
\(u = x + y\)\(5\)\(\bar u = y = 3\)
\(x\)\(2\)\(\bar x = \bar u \cdot 1 = 3\)
\(y\)\(3\)\(\bar y = \bar u \cdot 1 + \bar f \cdot u = 3 + 5 = 8\)

Check: \(f = xy + y^2\), so \(\partial f/\partial x = y = 3\) and \(\partial f/\partial y = x + 2y = 8\).

Forward sweeps or one reverse sweep

Forward mode needs a sweep per input. Reverse mode gets every input gradient in one sweep.

Act 4 / Forward or reverse

Which direction to sweep

Forward mode

One sweep per input. Cheap when there are few inputs and many outputs.

Reverse mode

One sweep per output. A loss is one output with millions of parameters: one backward pass gives every gradient.

Backpropagation is reverse-mode automatic differentiation on a neural network.

Act 4 / In code

What loss.backward() does

x = torch.tensor(2.0, requires_grad=True)
y = torch.tensor(3.0, requires_grad=True)
f = (x + y) * y      # forward: records the graph
f.backward()         # reverse sweep from f
print(x.grad, y.grad)  # tensor(3.) tensor(8.)

The same numbers as the table, with no formula for \(\partial f/\partial y\) ever written down.
