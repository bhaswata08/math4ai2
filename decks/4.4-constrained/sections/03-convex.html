Convex optimisation

The class of problems where "found a minimum" means "found the minimum".

Convex function: the chord stays above the graph

Pick any two points on the curve and join them. On a convex function the chord never dips below the graph.

Convex set: the segment stays inside

Any two points of a convex set can be joined by a segment that stays in the set. A crescent fails: the segment leaves it.

Convex: every start, one answer

Three gradient descent runs from three starts end at the same minimum.

Not convex: the start decides

On a double well the runs split: two reach the global minimum, one stops in the local one.

Act 3 / Definition

A convex problem

$$\min_{\mathbf x}\; f(\mathbf x) \quad \text{s.t.}\quad g_i(\mathbf x) \le 0,\quad A\mathbf x = \mathbf b$$

Terms

\(f\) is the objective. Each \(g_i\) is an inequality constraint. \(A\mathbf x = \mathbf b\) is a set of linear equality constraints. The feasible set is \(C = \{\mathbf x \mid g_i(\mathbf x) \le 0,\ A\mathbf x = \mathbf b\}\).

Requirements

\(f\) and every \(g_i\) convex. Then \(C\) is convex.

Payoff: every local minimum is a global minimum, and solvers find it reliably.

Act 3 / Inequalities

Inequality constraints: active or not

Minimise \(f(\mathbf x) = \lVert\mathbf x - \mathbf c\rVert^2\) (squared distance to a centre \(\mathbf c\)) subject to \(g(\mathbf x) = \lVert\mathbf x\rVert^2 - 1 \le 0\): the unit disc. Set \(\mathcal L = f + \lambda g\).

  • Centre outside: optimum on the boundary, \(g = 0\): active, \(\lambda > 0\)
  • Centre inside: free minimum: inactive, \(\lambda = 0\)

KKT: \(\nabla f + \lambda\nabla g = 0,\ \lambda \ge 0,\ \lambda\,g = 0\). Either the constraint binds (\(g = 0\)) or \(\lambda = 0\). Act 2 maximised with \(\mathcal L = f - \lambda(g - c)\); here we minimise, so the sign flips.
