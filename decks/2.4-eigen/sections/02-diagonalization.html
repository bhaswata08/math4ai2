Diagonalization

Use the eigenvectors as the axes. In that basis the matrix is just scaling.

20 min
Act 2 / Statement

\(A = PDP^{-1}\)

  • \(P\): eigenvectors as columns
  • \(D\): eigenvalues on the diagonal, in the same order
  • Possible when \(A\) has \(n\) independent eigenvectors

Read right to left: go to the eigenbasis, scale, come back.

Change basis, stretch, change back

\(P^{-1}\) sends the eigenvectors to the axes, \(D\) stretches, \(P\) sends the axes back.

Act 2 / Worked example

Our matrix, factored

$$\begin{bmatrix}4&1\\2&3\end{bmatrix} = \underbrace{\begin{bmatrix}1&1\\1&-2\end{bmatrix}}_{P}\underbrace{\begin{bmatrix}5&0\\0&2\end{bmatrix}}_{D}\underbrace{\tfrac13\begin{bmatrix}2&1\\1&-1\end{bmatrix}}_{P^{-1}}$$

Multiply it out once to see that it returns \(A\).

Act 2 / Powers

\(A^k = PD^kP^{-1}\)

The inner \(P^{-1}P\) pairs cancel, so only \(D\) is repeated:

$$D^k = \begin{bmatrix}5^k&0\\0&2^k\end{bmatrix}$$

Check \(k=3\): \(P\,\mathrm{diag}(125,8)\,P^{-1} = \begin{bmatrix}86&39\\78&47\end{bmatrix} = A^3\).

Power iteration

Multiply by \(A\) again and again, and any start swings onto the \(\lambda = 3\) direction.

Act 2 / Why it works

The biggest eigenvalue wins

Write \(\mathbf{x} = c_1\mathbf{v}_1 + c_2\mathbf{v}_2\). Then

$$A^k\mathbf{x} = c_1\lambda_1^k\mathbf{v}_1 + c_2\lambda_2^k\mathbf{v}_2$$

The term with the larger \(|\lambda|\) dominates, so the direction converges to \(\mathbf{v}_1\).
