Dimension

How many vectors a basis needs.

Count the basis vectors

A line needs 1, a plane needs 2, space needs 3. One more makes the set dependent. One fewer loses part of the span.

Act 2 / Definition

Dimension

$$\dim V = \textcolor{#f0a35e}{\text{number of vectors in any basis of } V}$$

Every basis of the same space has the same size, so the count is well defined.

spacea basisdimension
\(\mathbb{R}^2\)\(\hat\imath, \hat\jmath\)2

Act 2 / Where this shows up

An embedding lives in 768 dimensions

A BERT-style model turns each word into a list of 768 numbers.

$$\vec w \in \mathbb{R}^{768},\qquad \dim = 768$$

Every embedding is a combination of 768 basis vectors, one per coordinate.
