Rank

How many dimensions survive the map.

Rank is the dimension of the output

The plane stays a plane (rank 2), collapses to a line (rank 1), then to a point (rank 0).

Act 3 / Definition

Column space and rank

The column space is every output \(A\mathbf{x}\): all combinations of the columns of \(A\).

$$\operatorname{rank} A = \dim(\text{column space}) = \text{number of independent columns}$$

This is the span and independence of Blocks 1.3 and 1.4, applied to the columns.

Act 3 / Example

A rank-2 matrix

$$A = \begin{bmatrix}1&0&1\\0&1&1\\1&1&2\end{bmatrix}$$

The third column is the sum of the first two, so only two columns are independent. Rank 2, and \(\det A = 0\): the flat cube from the volume clip.

Act 3 / Square matrices

Three questions, one answer

For an \(n\times n\) matrix \(A\), these are equivalent:

  • \(A\) is invertible
  • \(\operatorname{rank} A = n\) (full rank)
  • \(\det A \neq 0\)

What is lost

Null space: every input that \(A\) sends to \(\mathbf{0}\), here the line along \((1,1,-1)\). Image: every output \(A\mathbf{x}\), here a plane, so rank 2. The dimensions add up: \(3 = 2 + 1\).

Act 3 / Rank–nullity

What is lost

$$n = \operatorname{rank} A + \dim(\text{null space})$$

Here \(n\) is the total number of input dimensions, the number of columns of \(A\). A \(5 \times 3\) matrix has \(n = 3\), a \(2 \times 4\) matrix has \(n = 4\).

The null space holds every input that \(A\) sends to \(\mathbf{0}\). For \(A = \begin{bmatrix}1&0&1\\0&1&1\\1&1&2\end{bmatrix}\), the first two columns add up to the third:

$$\text{col}_1 + \text{col}_2 = \begin{bmatrix} 1 \\ 0 \\ 1 \end{bmatrix} + \begin{bmatrix} 0 \\ 1 \\ 1 \end{bmatrix} = \begin{bmatrix} 1 \\ 1 \\ 2 \end{bmatrix} = \text{col}_3$$

Rewriting this gives:

$$\text{col}_1 + \text{col}_2 - \text{col}_3 = \mathbf{0}$$

That is \(A\) applied to \((1, 1, -1)\), so this input is sent to \(\mathbf{0}\). The null space is a line: \(3 = 2 + 1\).

What survives plus what vanishes always adds up to the input dimension.

Act 3 / By elimination

Rank from the RREF

Row-reduce \(A\) as in the Day 1 dependence test. Each pivot marks an independent column.

$$\begin{bmatrix}1&0&1\\0&1&1\\1&1&2\end{bmatrix}\xrightarrow{\;R_3 - R_1 - R_2\;}\begin{bmatrix}1&0&1\\0&1&1\\0&0&0\end{bmatrix}$$

Two pivots, so rank 2. Column 3 has no pivot, so \(x_3\) is free and \(x_1 = x_2 = -x_3\). Taking \(x_3 = -1\) gives \((1, 1, -1)\), the null-space line from the clip.

Rank = number of pivots. Null-space dimension = number of free columns.

What \(A\) does to space

The Day 1 matrix sends \(\hat\imath, \hat\jmath, \hat k\) to its columns \(\vec v, \vec w, \vec u\). All of space flattens onto the plane of \(\vec v\) and \(\vec w\), and the line along \((1,1,-1)\) goes to \(\mathbf 0\).

What row reduction does to space

The Day 1 columns \(\vec v, \vec w, \vec u\). Each row operation warps all of space. REF lays their plane on the floor; RREF puts \(\vec v, \vec w\) on the axes. \(\vec u = \vec v + \vec w\) at every step.

\(A\), REF and RREF as maps

The null line \((1,1,-1)\) goes to \(\mathbf 0\) in all three: the null space never changes. The image does: a tilted plane, then the floor, then the floor with the columns on the axes.
