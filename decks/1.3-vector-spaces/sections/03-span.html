Act 3 / Definition

The span of two vectors

$$\operatorname{span}(\textcolor{#6fd0c0}{\vec v}, \textcolor{#c792ea}{\vec w}) = \bigl\{\, \textcolor{#f0a35e}{a}\,\textcolor{#6fd0c0}{\vec v} + \textcolor{#f0a35e}{b}\,\textcolor{#c792ea}{\vec w} \;:\; a, b \in \mathbb{R} \,\bigr\}$$

The set of all linear combinations: every tip you can land on by choosing \(a\) and \(b\).

When the vectors line up

If \(\vec v\) and \(\vec w\) point along one line, every combination stays on it. If both are zero, only the origin is left.

Act 3 / Three cases

The plane, a line, or a point

Not parallel

The whole plane

Parallel

One line through the origin

Both zero

Only the origin

The span always contains the origin, since \(a = b = 0\) is allowed.

In three dimensions

Two vectors in 3D still span only a flat sheet through the origin.

Act 3 / Where this shows up

A linear layer can only reach a span

A layer with three outputs and two inputs.

$$W\vec x = x_1 \textcolor{#6fd0c0}{\vec c_1} + x_2 \textcolor{#c792ea}{\vec c_2}$$

Every output is a combination of the two columns of \(W\), so the outputs fill a plane inside 3D and never leave it.
