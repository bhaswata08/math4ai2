Vector spaces and subspaces

A space is a set of vectors you can add and scale without ever leaving it.

20 min
Act 5 / The spaces we know

\(\mathbb{R}^2\), \(\mathbb{R}^3\), \(\mathbb{R}^n\)

\(\mathbb{R}^2\): the whole plane

\(\textcolor{#6fd0c0}{(3, 2)}\), \(\textcolor{#c792ea}{(\pi, e)}\), \(\textcolor{#ffd166}{(0, 0)}\), …

\(\mathbb{R}^3\), \(\mathbb{R}^n\)

\(\mathbb{R}^3\): all vectors with 3 real numbers
\((3, 2, 0)\) lives in \(\mathbb{R}^3\), not \(\mathbb{R}^2\)
\(\mathbb{R}^n\): all vectors with \(n\) real numbers
An embedding with 768 numbers lives in \(\mathbb{R}^{768}\)

Add any two, scale by any number: you are still in \(\mathbb{R}^n\). That is what makes it a vector space.

Act 5 / The rule

What a vector space must allow

Add

\(\vec u + \vec v\) stays inside

Scale

\(c\,\vec v\) stays inside, for every \(c\)

Zero

\(0\,\vec v = \vec 0\), so \(\vec 0\) is always inside

In one line: every linear combination \(c\,\vec v + d\,\vec w\) stays inside.

Part of a space can fail

Adding never leaves the quarter plane, but \(-1\cdot\vec v\) does. It is not closed under scaling, so it is not a vector space.

One vector brings its whole line

A subspace is a vector space inside another one. Once \(\vec v\) is in, every \(c\,\vec v\) is in, \(\vec 0\) and \(-\vec v\) included: the whole line through \(\vec 0\).

The line must pass through 0

A line through the origin passes the test. A line that misses the origin fails: its sum leaves the line, and \(0\cdot\vec v\) is not on it.

Act 5 / Subspaces

Every subspace of \(\mathbb{R}^3\)

All of \(\mathbb{R}^3\)

Plane through 0

Line through 0

Just 0

In \(\mathbb{R}^2\) the list is shorter: all of \(\mathbb{R}^2\), lines through 0, and 0 alone. The span of any vectors is always one of these.

Act 5 / Check

Subspace of \(\mathbb{R}^2\), or not?

The x-axis

Subspace: \((a, 0) + (b, 0) = (a + b, 0)\)

Both axes

Not: \((1, 0) + (0, 1) = (1, 1)\) is off both axes

Just 0

Subspace: \(\vec 0 + \vec 0 = \vec 0\), \(c\,\vec 0 = \vec 0\)

The test is always the same: add two, scale one, and see whether you are still inside.

Act 5 · Bonus

Vectors that are not arrows

Anything you can add and scale is a vector. Polynomials, for one.

Bonus / Beyond arrows

Other things that add and scale

Polynomials

\(p = \textcolor{#6fd0c0}{1 + 2x}\)
\(q = \textcolor{#c792ea}{3 - x^2}\)
\(p + q = \textcolor{#f0a35e}{4 + 2x - x^2}\)
\(2p = \textcolor{#f0a35e}{2 + 4x}\)
Zero: the polynomial \(0\)

Functions

\(f(x) = \textcolor{#6fd0c0}{\sin x}\)
\(g(x) = \textcolor{#c792ea}{x^2}\)
\((f + g)(x) = \textcolor{#f0a35e}{\sin x + x^2}\)
\((3f)(x) = \textcolor{#f0a35e}{3\sin x}\)
Zero: the function that is always \(0\)

Model weights

\(w_A = \textcolor{#6fd0c0}{(0.2,\,-0.4,\,1.0)}\)
\(w_B = \textcolor{#c792ea}{(0.6,\,0,\,-0.2)}\)
\(\tfrac12(w_A + w_B) = \textcolor{#f0a35e}{(0.4,\,-0.2,\,0.4)}\)
\(2w_A = \textcolor{#f0a35e}{(0.4,\,-0.8,\,2.0)}\)
Averaging two models gives a model. Zero: all weights \(0\)

illustrative values

Polynomials are vectors

Add two polynomials, or scale one, and you get a polynomial again. The zero polynomial is the zero vector. That is all a vector space asks.

Coordinates of a polynomial

\(1, x, x^2, \dots\) play the part of \(\hat\imath\) and \(\hat\jmath\). Every polynomial is a linear combination of a few of them, and its scalars are its coordinates.

Adding building blocks one at a time

Each step adds one more block, so each step is a polynomial. Step by step the curves close in on \(e^x\).

Spaces inside spaces

Each box is a subspace of the next. Every step stays inside the polynomials; only the endless sum \(e^x\) lands outside.
