Act 3 / The formula

Projection onto a unit vector

$$P = uu^T,\qquad \|u\|=1$$

For \(u = \tfrac{1}{\sqrt5}\begin{bmatrix}1\\2\end{bmatrix}\): \(\;P=\tfrac15\begin{bmatrix}1&2\\2&4\end{bmatrix}=\begin{bmatrix}0.2&0.4\\0.4&0.8\end{bmatrix}\), the matrix in the clip.

  • \(P^2=P\): projecting twice changes nothing more.
  • Rank 1, \(\det P = 0\), so \(P\) is not invertible: many inputs share one output.

A projection destroys information, so there is no way back.
