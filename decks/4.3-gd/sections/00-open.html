Block 4.3 / Outcomes

After this block you can

  1. Run gradient descent by hand for a few steps
  2. Predict when a learning rate crawls, converges or diverges
  3. Explain why gradient descent zig-zags in a narrow valley
  4. Compare batch, mini-batch and stochastic gradient descent, and implement all three
